If the fast hammer does not respond, check that the game is in focus and that you are holding the correct hammer key. Some games require you to run the tool as administrator for input to work properly. You can right-click the app and choose "Run as administrator".

If the magnifier overlay does not appear, try switching the game to borderless windowed mode. Full-screen exclusive mode may block overlays on some systems.

If the mortar calculator shows unexpected results, double-check that you entered the coordinates in the correct order. The tool expects X, Y format for both mortar and target positions.
